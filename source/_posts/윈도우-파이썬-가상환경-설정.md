# 가상환경이란?

파이썬 가상환경(Virtual Environment)은 프로젝트별로 독립된 파이썬 실행 환경을 만드는 도구다.
각 가상환경은 자체적인 파이썬 인터프리터와 패키지 저장소를 가지므로, 프로젝트 간에 패키지 버전 충돌 없이 개발할 수 있다.

# 가상환경이 필요한 이유

## 패키지 버전 충돌 방지

프로젝트 A는 `Django 3.2`를, 프로젝트 B는 `Django 4.2`를 사용한다고 가정해보자.
가상환경 없이 전역(global) 환경에 패키지를 설치하면 두 버전을 동시에 유지할 수 없다.
가상환경을 사용하면 각 프로젝트가 독립적인 패키지 버전을 유지할 수 있다.

## 프로젝트 의존성 격리

전역 환경에 모든 패키지를 설치하면 시간이 지날수록 불필요한 패키지가 쌓여 관리가 어려워진다.
가상환경을 사용하면 프로젝트에 필요한 패키지만 설치되어 깔끔하게 관리할 수 있다.

## 재현 가능한 개발 환경

`requirements.txt`로 의존성 목록을 관리하면 팀원이나 서버에서 동일한 환경을 손쉽게 재현할 수 있다.

# 윈도우에서 가상환경 설정하기

파이썬 3.3 이상부터는 `venv` 모듈이 기본 내장되어 있어 별도 설치 없이 사용 가능하다.

## 1. 파이썬 설치 확인

```bash title-test
python --version
```

버전 정보가 출력되면 정상적으로 설치된 것이다.

## 2. 프로젝트 폴더 생성 및 이동

```bash
mkdir my-project
cd my-project
```

## 3. 가상환경 생성

```bash
python -m venv venv
```

명령어 실행 후 프로젝트 폴더 안에 `venv` 디렉터리가 생성된다.
`venv` 대신 원하는 이름을 사용해도 되지만, 관례적으로 `venv` 또는 `.venv`를 많이 사용한다.

```
my-project/
└── venv/
    ├── Include/
    ├── Lib/
    ├── Scripts/
    └── pyvenv.cfg
```

## 4. 가상환경 활성화

윈도우 **명령 프롬프트(CMD)**:

```bash
venv\Scripts\activate
```

윈도우 **PowerShell**:

```bash
venv\Scripts\Activate.ps1
```

> **PowerShell 실행 정책 오류가 발생하는 경우**
> PowerShell에서 스크립트 실행이 차단될 수 있다. 아래 명령어로 현재 사용자에 한해 실행을 허용한다.
> ```bash
> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
> ```

활성화되면 프롬프트 앞에 `(venv)`가 표시된다.

```bash
(venv) C:\my-project>
```

## 5. 패키지 설치

가상환경이 활성화된 상태에서 `pip`로 패키지를 설치하면 해당 가상환경에만 설치된다.

```bash
pip install requests
pip install django==4.2
```

## 6. 의존성 저장 및 복원

현재 설치된 패키지 목록을 파일로 저장:

```bash
pip freeze > requirements.txt
```

다른 환경에서 동일한 패키지 설치:

```bash
pip install -r requirements.txt
```

## 7. 가상환경 비활성화

```bash
deactivate
```

프롬프트에서 `(venv)` 표시가 사라지면 비활성화된 것이다.

---

# `.gitignore`에 가상환경 추가

가상환경 폴더는 용량이 크고 OS마다 다르게 생성되므로 Git에 올리지 않는 것이 원칙이다.
프로젝트 루트의 `.gitignore`에 다음을 추가한다.

```
venv/
.venv/
```

# 요약

| 단계 | 명령어 |
|------|--------|
| 가상환경 생성 | `python -m venv venv` |
| 활성화 (CMD) | `venv\Scripts\activate` |
| 활성화 (PowerShell) | `venv\Scripts\Activate.ps1` |
| 패키지 설치 | `pip install <패키지명>` |
| 의존성 저장 | `pip freeze > requirements.txt` |
| 의존성 복원 | `pip install -r requirements.txt` |
| 비활성화 | `deactivate` |
